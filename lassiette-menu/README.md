# L'Assiette — Menu digital

Menu QR code du restaurant L'Assiette (Brazzaville). Page unique : `index.html`.

## Mise en ligne (GitHub Pages)
1. Settings > Pages
2. Source : Deploy from a branch, branche `main`, dossier `/ (root)`
3. Le menu sera disponible sur `https://<utilisateur>.github.io/<repo>/`

Ce lien sert ensuite à générer le QR code.

## Modifier un prix ou un plat
Ouvrir `index.html` et chercher le nom du plat : chaque plat est une ligne `<li class="item">`.
